Technologies Learned & Explored

Below are some key web development terms and concepts I have learned so far:

HTML5
The standard markup language used to create the structure of web pages.
Semantic Elements
Tags that clearly describe their meaning to both the browser and the developer (e.g., header, footer, article).
Web Accessibility
The practice of designing websites so that everyone, including people with disabilities, can use them.
Open Source
Software with source code that anyone can inspect, modify, and enhance.
